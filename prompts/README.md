# 网页版 AI 用的提示词

不用 Cursor、Claude Code 这类 agent，也能用这套方法：把提示词复制进 ChatGPT、Claude、Gemini、DeepSeek、Kimi、豆包等任意聊天窗口，把 `{{双花括号}}` 换成你的内容。用不上的小节整段删掉。

| 文件 | 用途 |
| --- | --- |
| [01-构思.md](01-构思.md) | 一句话想法，扩成三个真正不同的故事方案 |
| [02-人物卡.md](02-人物卡.md) | 主要人物的人物卡 |
| [03-细纲.md](03-细纲.md) | 一批章节的细纲 |
| [04-写正文.md](04-写正文.md) | 按细纲写一章（只含正面写法，不含 AI 腔清单） |
| [05-去AI味.md](05-去AI味.md) | 改稿：去掉 AI 腔 |
| [06-文风学习.md](06-文风学习.md) | 从样本提炼文风；对比 AI 原稿和你的改稿 |
| [07-审稿.md](07-审稿.md) | 一致性检查、读者模拟、打分、修改清单 |

## 三条建议

1. **写和改分开对话。** 用 04 在一个对话里写，用 05 另开一个新对话改。写作的对话里不要贴 AI 腔清单，清单里的词会被模型反复想起。
2. **设定放在你自己的文档里。** 可以照 [`skills/renwei-novel/assets/workspace/`](../skills/renwei-novel/assets/workspace/) 的结构建文件夹。每次只把这一章需要的部分贴进去，不要指望 AI 记得上一次对话。
3. **改完量化一下。** 装了 Node.js 的话，用检测脚本看看 AI 腔指数降了没有：

   ```bash
   node skills/renwei-deai/scripts/deai-check.mjs 你的章节.md
   ```
