# 细纲

```text
请为接下来的 {{数量}} 章写细纲。

全书大纲：{{贴入}}
人物卡：{{贴入主要人物}}
前情摘要：{{最近几章发生了什么}}
伏笔表：{{还没收的伏笔，以及计划在这几章埋下的}}

每章按这个格式写：
- 功能：推进 / 铺垫 / 爆发 / 喘息（不要连续三章同一种）
- 视角人物
- 字数目标
- 本章新信息：读者读完这一章新知道了什么（不能为空）
- 埋伏笔 / 收伏笔
- 场景列表：每个场景写地点、在场人物、谁想要什么、什么挡着、结束时变了什么（每个场景都必须有变化，没有变化的合并或删掉）
- 结尾落点：从“新信息 / 决定 / 危险逼近 / 安静的画面 / 戛然而止”里选，相邻两章不要用同一种
- 本章禁止：不能在这一章揭露的东西
```
