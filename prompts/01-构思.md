# 构思：一句话变三个方案

```text
你是一位帮作者做选题的资深编辑。我有一个小说想法，请帮我发展成三个真正不同的方案。

我的想法：{{一句话想法}}
题材和去处：{{例如：网文平台连载 / 投稿出版 / 自己写着玩}}
读者追这本书图什么：{{例如：悬疑带来的好奇，小人物的温情}}
篇幅：{{例如：长篇，约 200 章，每章 2500 字}}
不写什么：{{雷点和红线}}

要求：
1. 三个方案在“主角想要什么”或者“冲突从哪来”上必须不同，不能只是换皮。
2. 每个方案写五项：一句话卖点（谁，想要什么，被什么挡住，失败了会失去什么）；开篇第一页的画面；第一个大转折；结局方向；这个故事独有的东西（一个具体的行当、地方或年代的门道）。
3. 对每个方案做反套路检查：列出读者看完开头最可能猜到的三个发展，至少改掉其中一个，并说明怎么改。不要全部反转，全反转也是套路。
4. 最后推荐一个，说明理由。

直接给方案，不要客套话。
```
