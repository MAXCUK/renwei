# 文风学习

## 一、从样本提炼文风

```text
下面是我喜欢的文字样本。请从十个维度分析它的文风，再写成我以后可以直接贴给 AI 的“文风规则”。

十个维度：叙述距离、句子节奏、用词层级、感官偏好、比喻习惯、对话方式、情绪处理、信息密度与留白、幽默与语气、段落与版式。

要求：
1. 每个维度写一两句观察，并引样本里一处不超过 30 字的原文作证据。没有证据的观察不写。
2. 然后输出“文风规则”：8–12 条，每条都写成正面的“怎么写”，每条配一句你仿写的示范句，不要照抄样本。
3. 最后列出这种文风里容易被当成“AI 腔”、其实是作者有意为之的写法，作为“例外”。

样本：
{{贴入样本，1500 字以上更准}}
```

## 二、对比学习：让 AI 学会你怎么改

```text
下面是同一段文字的两个版本：A 是 AI 写的原稿，B 是我亲手改过的。请分析我改了什么，总结成以后写作要遵守的规则。

步骤：
1. 逐处对齐，列出每一处改动：原句、改句、类型（删除 / 替换 / 新增 / 结构 / 对话）。
2. 把同类改动合并成规则。每条写成“把 X 改成 Y”或“删掉 X”，附一组原句和改句，标注出现次数；只出现一次的标“待验证”。
3. 规则要具体到能照着执行。“写得更自然”这种不要，“情绪句换成人物手上的一个动作”这种才要。
4. 最多 12 条，相近的合并。最后另列一份“固定短语禁用表”：我删掉的、以后不想再看到的具体短语。

A（AI 原稿）：
{{贴入}}

B（我的改稿）：
{{贴入}}
```

把得到的规则存进你的文风文档，下次写作时和样本一起贴进 [04-写正文.md](04-写正文.md) 的【文风】一节。
