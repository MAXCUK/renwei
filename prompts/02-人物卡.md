# 人物卡

```text
请为下面这个故事写主要人物的人物卡。

故事方案：{{贴入选定的方案}}
需要的人物：{{例如：主角、导师、对手、一个配角}}

每张卡包括：
- 身份
- 想要什么（外在目标）
- 需要什么（他自己没意识到的缺失）
- 害怕什么
- 一个会真的惹出麻烦的缺陷（“太善良”这种不算）
- 一个秘密
- 说话方式：句子长短、口头禅、用词、方言行话、回避的话题
- 三句示例台词
- 他知道什么、不知道什么
- 和主角的关系，张力在哪
- 弧光：开始时相信什么，结尾时相信什么（也可以拒绝改变）

要求：
- 每个人都有自己的算盘，不是围着主角转的工具人。
- 反派的逻辑在他自己看来成立，最好有一处读者会同意他。
- 写完做一次区分度测试：把所有人的示例台词去掉名字混在一起，检查能不能分出是谁说的；分不出就改，直到分得出来。
```
