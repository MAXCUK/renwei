# 对比学习

用户每改一处，都在告诉你他要什么。把这些改动归类、计数、写成规则，就得到一份只属于这个作者的文风说明。

## 修改的五种类型

| 类型 | 常见改动 | 写成规则的样子 |
| --- | --- | --- |
| 删除 | 删套话、删解释动作含义的句子、删段末总结、删重复 | “删掉解释动作含义的句子，动作写完就停。” |
| 替换 | 抽象换具体、书面换口语、情绪词换动作、大词换小词、副词加动词换成一个准确的动词 | “情绪句换成人物手上的一个动作。” |
| 新增 | 加物件细节、加数字和时间、加方言行话、加人物的小动作和小失误、加另一种感官 | “每个场景至少有一个带数字的细节（几点、几号、多少钱）。” |
| 结构 | 拆长句、合碎句、调语序、合并单句段、改结尾落点 | “章末停在画面上，不留感悟句。” |
| 对话 | 删说话人标签、改口语、加打断、问答不对称、把直说改成潜台词 | “问的人常常得不到直接回答。” |

## 步骤

1. **量化。** `node scripts/style-fingerprint.mjs --compare 原稿.md 改稿.md` 给出指标变化，以及改稿删掉、新加的高频词组。两份各跑一次 renwei-deai 的检测，看消掉了哪些 AI 腔。
2. **对齐。** 按段落对照，把每一处改动记成“原句 / 改句 / 类型”。
3. **归纳。** 同类改动合并成一条规则，往上概括一层，但不要概括成空话。
   - 太具体：“把‘深吸一口气’删掉。”（这种可以直接进禁用词表）
   - 刚好：“推门、开口这类动作前面不加呼吸和心跳。”
   - 太空：“写得更自然。”
4. **计数。** 每条规则标注在这次对比里出现了几次。只出现一次的标“待验证”，下次对比再确认。
5. **落盘。** 追加到 `设定/文风.md` 的“对比学习规则”，固定短语进 `设定/禁用词.txt`。用户刻意保留的写法记进“例外”。

## 完整示例

仓库 `examples/` 里有一对样稿：`夜班-AI原稿.md` 和 `夜班-改稿.md`，同一个场景。对比脚本的部分输出：

```text
句长变异系数            0.52      0.72  +38%
单句段占比               57%       30%  -27 个百分点
对话占比                  4%       16%  +12 个百分点
比喻词/千字              5.9         0  -100%
“了”/百字               2.37      4.48  +89%

改稿删掉或少用的：想起（3→0） · 第一次（2→0） · 值夜班（2→0） · 空气（2→0） · 一阵（2→0） · 心头（2→0） · 缓缓（2→0） · 仿佛（2→0） …
改稿新加或多用的：老周（2→5） · 一盏（0→4） · 什么响动（0→2） · 一盏一盏（0→2） · 老周把（0→2） · 登记本（0→2） …
```

从这对样稿归纳出的规则：

1. **开头交代具体地点，不写天气套话。**（替换，1 次，待验证）
   原：夜色如墨，县城殡仪馆的走廊里空无一人。
   改：殡仪馆在县城最北头，过了加油站再走五百米。
2. **气味按闻到的先后写，最多两种，不说“弥漫”。**（替换，1 次，待验证）
   原：空气中弥漫着消毒水的味道，冰冷的、刺鼻的、陌生的气息扑面而来。
   改：他推开，先闻到的是消毒水，然后才是老周的烟。
3. **情绪句一律删掉，换成人物手上的小动作或小失误。**（替换，4 次）
   原：他感到一阵莫名的不安。……心头一紧。……让他五味杂陈。
   改：钉子松了，头盔往下滑了一截，他又扶了一下。／拉链拉到一半卡住了。／掰了一块，没往嘴里送。
4. **台词短，问答不对称，问题可以没人回答。**（对话，2 次）
   原：老周眼中闪过一丝不易察觉的担忧，沉默了片刻，缓缓开口：“今晚，可能会有点不一样。”
   改：“什么响动？”老周没接这话。
5. **不用副词修饰“说”，大部分台词不加标签。**（对话，2 次）
   原：“来了？”他淡淡地说道。
   改：老周把烟按灭在茶杯盖上。“来了？”
6. **用具体的数字和时间代替模糊的时间流逝。**（新增，4 次）
   原：时间缓缓流逝。不知过了多久，
   改：冷库三号柜……家属明天八点到。……十一点四十，
7. **悬念放进一个反常的细节里，不让叙述者预告。**（替换，1 次，待验证）
   原：陈默不知道的是，一场风暴正在酝酿。
   改：十一点四十，走廊尽头的灯亮了。没有脚步声。
8. **删掉所有议论和总结句，章末停在画面上。**（删除，4 次）
   原：与其说是恐惧，不如说是一种期待。……或许，这就是命运吧。而这，只是开始。
   改：没有脚步声。

其中第 3、6、8 条可以直接进写法规则；“空气中弥漫着”“不知过了多久”这类固定短语，内置的去 AI 味规则已经覆盖，不用再进禁用词表。
