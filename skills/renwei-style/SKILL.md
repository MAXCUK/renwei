# 人味 · 文风

让 AI 照着具体的样本写，而不是照着“生动、细腻、有画面感”这种形容词写。

## 三个用法

| 用法 | 用户提供 | 产出 |
| --- | --- | --- |
| 样本建档 | 1–3 段喜欢的文字 | `设定/文风.md`、`设定/文风指纹.json` |
| 对比学习 | 同一段的 AI 原稿和用户改稿 | `设定/文风.md` 里的“对比学习规则”，必要时追加 `设定/禁用词.txt` |
| 漂移检查 | 新写的章节 | 偏离报告和回拉建议 |

脚本路径相对本 skill 所在目录。不在小说工作区里时，把结果写到用户指定的位置，或者直接在对话里给出。

## 一、样本建档

1. **要样本。** 1–3 段，合计 1500 字以上更准。最好是叙事段落，带对话，同一个视角。用户自己的旧稿最好，喜欢的作家片段也行。
2. **量化：**
   ```bash
   node scripts/style-fingerprint.mjs <样本文件…> --save 设定/文风指纹.json
   ```
3. **定性：** 按 `references/style-dimensions.md` 的十个维度逐项观察。每项引样本里一处不超过 30 字的原文作证据，没有证据的观察不写。
4. **写 `设定/文风.md`**，格式见下文。规则一律写成正面的“怎么写”，每条配一句你自己仿写的示范句，不照抄样本。
5. **给用户确认**，确认后才在写作中使用。

样本是已出版作品时：文风.md 里只引短句作证据，学技法，不学内容，不要把大段原文存进工作区。

## 二、对比学习

这是让 AI 学会用户口味最快的办法：用户改过的每一处，都是一条现成的规则。

1. 拿到同一段的 AI 原稿和用户改稿，各存一个文件。
2. 量化差异：
   ```bash
   node scripts/style-fingerprint.mjs --compare 原稿.md 改稿.md
   ```
   如果也装了 renwei-deai，对两份各跑一次它的 `deai-check.mjs`，看改稿消掉了哪些 AI 腔。
3. 逐处对齐，找出删除、替换、新增、调序和对话上的改动。分类方法见 `references/contrast-learning.md`。
4. 总结规则。每条写成“把 X 改成 Y”或“删掉 X”，附一组原句和改句，标注出现次数；只出现一次的标“待验证”。最多 12 条，相近的合并。规则要具体到能执行：“写得更具体”没法执行，“情绪句换成人物手上的一个动作”可以。
5. 落盘：
   - 规则追加到 `设定/文风.md` 的“对比学习规则”。
   - 能写成固定短语的禁用写法，追加到 `设定/禁用词.txt`。
   - 用户坚持保留、但会被去 AI 味检测标出来的写法，记进“例外”，同时把对应规则 id 加进 `设定/去AI味.json` 的 `allow`。

## 三、漂移检查

1. 运行：
   ```bash
   node scripts/style-fingerprint.mjs 正文/第NNN章.md --baseline 设定/文风指纹.json
   ```
2. 3 项及以上偏离算漂移。指出最明显的两个方向（例如“对话占比从 35% 掉到 12%，平均句长多了 40%”），给出回拉的具体改法。1–2 项偏离只提示。
3. 漂移不一定是坏事。打斗章句子变短、回忆章对话变少都正常，由用户决定要不要拉回来。

## 文风.md 的格式

```markdown
# 文风

## 样本出处
- 样本 1：用户旧稿第 3 章，约 1200 字

## 写法规则
1. 叙述贴着主角走，只写他看得见、想得到的。
   示范：他没看清那人的脸，只记得一双很新的皮鞋。
2. 对话短，常常答非所问；大部分台词不加说话人标签。
   示范：“吃了没？”“三号柜的家属几点到？”

## 数值目标（来自 设定/文风指纹.json）
- 平均句长 14–20 字，短句占三成左右
- 对话占比 30%–40%
- 每千字比喻词不超过 1 个

## 例外（去 AI 味时不要改）
- 用破折号表示话被打断，保留。

## 对比学习规则
1. 情绪句换成人物手上的一个动作。（3 次）
   原：他感到一阵心酸。
   改：他把烟掐了，又点了一根。
```

## 写正文时怎么用

写正文前读 `设定/文风.md` 的写法规则、数值目标、对比学习规则和示范句，照着写。不要在写作时加载 renwei-deai 的套话清单（写和改分开）。

## 文件

- `scripts/style-fingerprint.mjs`：文风指纹，统计句长分布、段长、对话占比、标点习惯、比喻和虚词密度、句首用字、高频词组。Node.js 18.3 以上，不需要安装依赖。
- `references/style-dimensions.md`：十个观察维度，以及怎么把观察写成规则。
- `references/contrast-learning.md`：对比学习的修改分类和一个完整示例。
